# Logger Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A rotated JSON-lines log of what the app did and what went wrong, read in a fifth manager section.

**Architecture:** Main owns the file (`log-store.ts`) and logs its own events through one facade
(`log-ipc.ts`). The renderer logs every error the status bar shows and reads the log over IPC. The
pure decisions (parsing, rotation, filtering, entry wording, card moves) live in tested modules.

**Tech Stack:** Electron, TypeScript, node:fs (sync), vitest (node environment only).

**Spec:** `docs/superpowers/specs/2026-10-24-logger-design.md`

## Global Constraints

- Card `7dbfc844-78a3-4661-9b7b-a855fe3eefe3`, branch `logger`, one pull request.
- Files: `dashboard.log`, `dashboard.log.1` … `dashboard.log.4` in `app.getPath('userData')`; 5 MB each, 25 MB total.
- Never logged: pane output, typed text, command-screen command text, `.env` or settings contents.
- `main.ts` and `renderer.ts` stay at or under 600 code lines. Count with
  `grep -cv '^\s*\(//.*\)\?$' <file>` (blank and comment-only lines excluded).
- IPC channels are `<noun>:<verb>`: `log:write`, `log:read`, `log:appended`.
- Every `<input>` gets `dir = 'auto'`; the two grep counts in CLAUDE.md agree.
- A class that sets `display` gets a `[hidden] { display: none }` rule beside it.
- No abbreviations in identifiers. Comments explain why, in the surrounding files' voice.
- Writes are synchronous (`appendFileSync`). Main is one thread, so two entries cannot interleave and
  no rotation can run twice; this replaces the spec's "one promise chain" with the same guarantee.
- `package.json` version `1.15.3` → `1.16.0`.
- Never quit, restart or reinstall the running Dashboard app. Checks only.

## Review Focus

1. A truncated last line (crash mid-write) or a hand-edited garbage line: the log section still opens
   and shows every good line. Pinned in Task 1 (`parseLogLine`) and Task 2 (`tail`).
2. One entry bigger than the 5 MB limit on an empty file: written, no rotation loop, no lost files.
   Pinned in Task 1 (`needsRotation` with size 0) and Task 2.
3. A board that fails to save every few seconds repeats the same status-bar message: the log gets it
   once, not once per repaint. Pinned in Task 5 (`shouldLogError`).
4. The app's own first write to a board it never read (the manager's cards view writes every
   project's board): the move is still logged. Pinned in Task 4 (`boardChanges` falls back to `peek`).
5. Fewer than 1000 entries across several rotated files, or files missing in the middle: `tail`
   returns all of them oldest first. Pinned in Task 2.

```ts
import type { ShipRequest, ShipResult, WorktreeRemoval } from './bridge';
import { paneLabel } from './terminals';

// One line of the log, and every decision about the file that does not touch the disk. Shared: main
// writes entries and the renderer reads and filters them, so both sides import the one shape.
export const LOG_LEVELS = ['error', 'warn', 'info'] as const;
export type LogLevel = typeof LOG_LEVELS[number];
export const LOG_KINDS = ['app', 'project', 'pane', 'agent', 'card', 'ship', 'worktree', 'board', 'error'] as const;
export type LogKind = typeof LOG_KINDS[number];

export type LogEntry = { time: string; level: LogLevel; kind: LogKind; project?: string; message: string };
// What a writer hands over. The time is stamped where the line is written, so every entry in the file
// is on main's clock whichever side of the wire it came from.
export type LogDraft = Omit<LogEntry, 'time'>;
// What the log section reads: the newest entries, oldest first, and where the file is for anything
// older than those.
export type LogRead = { file: string; entries: LogEntry[] };

export const LOG_FILE = 'dashboard.log';
export const LOG_FILE_COUNT = 5;
export const LOG_FILE_LIMIT = 5 * 1024 * 1024;
export const LOG_READ_COUNT = 1000;

// Undefined for anything that is not an entry. A crash mid-write leaves half a line at the end of the
// file, and a person may edit it by hand; either costs that one line, never the section.
export function parseLogLine(line: string): LogEntry | undefined {
  let value: unknown;
  try {
    value = JSON.parse(line);
  } catch {
    return undefined;
  }
  if (typeof value !== 'object' || value === null) return undefined;
  const { time, level, kind, project, message } = value as Record<string, unknown>;
  if (typeof time !== 'string' || typeof message !== 'string') return undefined;
  if (!LOG_LEVELS.some((known) => known === level) || !LOG_KINDS.some((known) => known === kind)) return undefined;
  if (project !== undefined && typeof project !== 'string') return undefined;
  return {
    time, level: level as LogLevel, kind: kind as LogKind, ...(project === undefined ? {} : { project }), message,
  };
}

// The live file first, the oldest last: rotation renames each one a place down this list.
export function logFileNames(base: string, count: number): string[] {
  return Array.from({ length: count }, (_, index) => (index === 0 ? base : `${base}.${index}`));
}

// An empty file is never rotated, so one entry bigger than the limit is written rather than pushing
// every older file off the end on its way to a file it still does not fit in.
export function needsRotation(currentSize: number, appendSize: number, limit: number): boolean {
  return currentSize > 0 && currentSize + appendSize > limit;
}

// Every word of the query, anywhere in the row as it reads. `error card` is the failed card writes.
export function matchesLogFilter(entry: LogEntry, query: string): boolean {
  const text = [entry.level, entry.kind, entry.project ?? '', entry.message].join(' ').toLowerCase();
  return query.toLowerCase().split(/\s+/).filter((word) => word !== '').every((word) => text.includes(word));
}

function inProject(project: string | undefined): { project?: string } {
  return project === undefined ? {} : { project };
}

// A non-zero exit is a warning, not an error: a shell you typed `exit 1` into is not the app failing.
export function paneExitEntry(project: string | undefined, index: number, exitCode: number, wasAgent: boolean): LogDraft {
  const pane = wasAgent ? `agent in ${paneLabel(index)}` : paneLabel(index);
  return {
    level: exitCode === 0 ? 'info' : 'warn', kind: wasAgent ? 'agent' : 'pane', ...inProject(project),
    message: `${pane} exited (code ${exitCode})`,
  };
}

export function agentStartEntry(project: string | undefined, index: number): LogDraft {
  return { level: 'info', kind: 'agent', ...inProject(project), message: `agent started in ${paneLabel(index)}` };
}

export function shipEntry(request: ShipRequest, result: ShipResult): LogDraft {
  const project = request.projectPath;
  if (result.ok) return { level: 'info', kind: 'ship', project, message: `"${request.title}" shipped on ${result.entry.branch}` };
  return { level: 'error', kind: 'ship', project, message: `"${request.title}" not shipped: ${result.message}` };
}

// A refusal is a warning: a worktree with changes in it asks you a second time, it does not fail.
export function removalEntry(projectPath: string, worktreePath: string, result: WorktreeRemoval): LogDraft {
  if (result.ok) return { level: 'info', kind: 'worktree', project: projectPath, message: `removed ${worktreePath}` };
  return { level: 'warn', kind: 'worktree', project: projectPath, message: `not removed ${worktreePath}: ${result.message}` };
}
```

```ts
import type { Board } from './board';

// Which cards changed column between two reads of one board, as the log says it. Only moves: a reorder
// inside a column is noise, and a card added or deleted is on the board itself to see.
export function cardMoves(before: Board, after: Board): string[] {
  const columnOf = new Map<string, string>();
  for (const column of before.columns) for (const card of column.cards) columnOf.set(card.id, column.name);
  const moves: string[] = [];
  for (const column of after.columns) {
    for (const card of column.cards) {
      const from = columnOf.get(card.id);
      if (from !== undefined && from !== column.name) moves.push(`"${card.title}" ${from} → ${column.name}`);
    }
  }
  return moves;
}
```

```ts
import { appendFileSync, readFileSync, renameSync, rmSync, statSync } from 'node:fs';
import path from 'node:path';
import {
  LOG_FILE, LOG_FILE_COUNT, LOG_FILE_LIMIT, logFileNames, needsRotation, parseLogLine,
  type LogDraft, type LogEntry,
} from './log-entry';

// The log on disk: five files of 5 MB, the live one first. Main-process only, and no electron in it, so
// rotation is tested on a real folder. Synchronous on purpose: main is one thread, so two entries can
// never interleave in the file or start the same rotation twice, and an append is microseconds.
export type LogStore = { file: string; log(draft: LogDraft): void; tail(count: number): LogEntry[] };

function sizeOf(file: string): number {
  try {
    return statSync(file).size;
  } catch {
    return 0;
  }
}

export function logStore(directory: string, onAppended: (entry: LogEntry) => void, limit = LOG_FILE_LIMIT): LogStore {
  const files = logFileNames(path.join(directory, LOG_FILE), LOG_FILE_COUNT);

  // The oldest goes, then every file moves a place down. A file missing from the middle is skipped:
  // there is nothing of it to move.
  function rotate(): void {
    rmSync(files[files.length - 1], { force: true });
    for (let index = files.length - 2; index >= 0; index--) {
      try {
        renameSync(files[index], files[index + 1]);
      } catch {
        // Nothing at this place in the list.
      }
    }
  }

  // A write that fails costs that entry and nothing else. Logging is never a reason for the thing being
  // logged to fail, and the terminal the app started from still hears about it.
  function log(draft: LogDraft): void {
    const entry: LogEntry = { time: new Date().toISOString(), ...draft };
    const line = `${JSON.stringify(entry)}\n`;
    try {
      if (needsRotation(sizeOf(files[0]), Buffer.byteLength(line), limit)) rotate();
      appendFileSync(files[0], line);
    } catch (error: unknown) {
      console.error('log entry not written:', error);
      return;
    }
    try {
      onAppended(entry);
    } catch (error: unknown) {
      console.error('log entry not announced:', error);
    }
  }

  // The newest `count`, oldest first. Files are read newest first and stop as soon as there are enough,
  // so the usual read is the live file alone.
  function tail(count: number): LogEntry[] {
    const entries: LogEntry[] = [];
    for (const file of files) {
      let text: string;
      try {
        text = readFileSync(file, 'utf8');
      } catch {
        continue;
      }
      entries.unshift(...text.split('\n').flatMap((line) => parseLogLine(line) ?? []));
      if (entries.length >= count) break;
    }
    return entries.slice(-count);
  }

  return { file: files[0], log, tail };
}
```

```ts
import type { Board } from './board';
import { cardMoves } from './card-moves';
import type { LogDraft } from './log-entry';

// Card moves, for the log. The last board each project was read or written with is kept here, and each
// new one is compared with it: a write from the app is a `card` entry, a change from the `board`
// command is a `board` one. `peek` is board-store's, handed in so this is tested without a folder.
export type BoardChanges = {
  seen(projectPath: string, board: Board): void;
  wrote(projectPath: string, board: Board): void;
  changed(projectPath: string): void;
};

export function boardChanges(log: (draft: LogDraft) => void, peek: (projectPath: string) => Board | null): BoardChanges {
  const last = new Map<string, Board>();

  function record(projectPath: string, before: Board | undefined | null, after: Board, fromCommand: boolean): void {
    last.set(projectPath, after);
    if (!before) return;
    for (const move of cardMoves(before, after)) {
      log({
        level: 'info', kind: fromCommand ? 'board' : 'card', project: projectPath,
        message: fromCommand ? `board command moved ${move}` : move,
      });
    }
  }

  return {
    seen: (projectPath, board) => { last.set(projectPath, board); },
    // Called before the write lands, so a board the app never read — the manager writes every open
    // project's — is compared with what is still on disk.
    wrote: (projectPath, board) => record(projectPath, last.get(projectPath) ?? peek(projectPath), board, false),
    changed: (projectPath) => {
      const board = peek(projectPath);
      if (board) record(projectPath, last.get(projectPath), board, true);
    },
  };
}
```

```ts
export type StatusError = { element: HTMLElement; show(owner: string, message: string): void };

// The status bar's error span. Out of renderer.ts, which had reached its 600-line ceiling.

// (Move the existing comments above `statusError`, `errorOwner` and `bridge.onFailure` here unchanged.)

// Every message it shows is also a line in the log, which is the one place every error a person sees

export function createStatusError(bridge: DashboardBridge): StatusError {
  const element = document.createElement('span');
  element.className = 'error';

  function show(owner: string, message: string): void {
    if (message === '' && errorOwner !== owner) return;
```

```ts
import type { Action } from './actions';
import type { DashboardBridge } from './bridge';
import { clampIndex } from './clamp-index';
import { failureText } from './failure';
import { LOG_READ_COUNT, matchesLogFilter, type LogEntry } from './log-entry';

export type LogOptions = {
  bridge: DashboardBridge;
  // The status bar's error span, under this section's own owner.
  onError(message: string): void;
};

export type LogView = {
  element: HTMLElement;
  // Arriving: the newest entries are read again and the filter box takes the keyboard. Never rejects.
  open(): Promise<void>;
  focus(): void;
  runAction(action: Action): void;
};

// The manager's log section: the newest thousand entries, newest at the top, with a box above them that
// narrows them the way the command box sits above the command screen. The box has the keyboard, so the
// screen's keys are arrows, Enter and Escape and nothing a filter would want to type.
export function createLogView(options: LogOptions): LogView {
  const element = document.createElement('div');
  element.className = 'view view-log';
  element.tabIndex = -1;
  const input = document.createElement('input');
  input.className = 'command-input log-filter';
  input.type = 'text';
  input.placeholder = 'Filter: error, card, a project name';
  // Every box you type into carries this; see the command box.
  input.dir = 'auto';
  const file = document.createElement('p');
  file.className = 'log-file';
  const list = document.createElement('ul');
  list.className = 'command-list log-list';
  const empty = document.createElement('p');
  element.append(input, file, list, empty);

  // Oldest first, as the file holds them; drawn reversed.
  let entries: LogEntry[] = [];
  const unfolded = new Set<LogEntry>();
  let selected = 0;
  let shown: LogEntry[] = [];

  function render(): void {
    shown = entries.filter((entry) => matchesLogFilter(entry, input.value)).reverse();
    selected = clampIndex(selected, shown.length - 1);
    list.replaceChildren(...shown.map((entry, index) => {
      const row = document.createElement('li');
      row.className = `log-row level-${entry.level}`;
      row.classList.toggle('highlighted', index === selected);
      row.classList.toggle('unfolded', unfolded.has(entry));
      const project = entry.project === undefined ? '' : `  ${entry.project}`;
      row.textContent = `${new Date(entry.time).toLocaleString()}  ${entry.level}  ${entry.kind}${project}  ${entry.message}`;
      // A click is the selection moving there, then what Enter does there.
      row.addEventListener('click', () => {
        selected = index;
        toggle();
      });
      return row;
    }));
    empty.hidden = shown.length > 0;
    empty.textContent = entries.length === 0 ? 'Nothing logged yet.' : 'Nothing matches the filter.';
    list.children[selected]?.scrollIntoView({ block: 'nearest' });
  }

  function toggle(): void {
    const entry = shown[selected];
    if (entry === undefined) return;
    if (unfolded.has(entry)) unfolded.delete(entry);
    else unfolded.add(entry);
    render();
  }

  input.addEventListener('input', () => {
    selected = 0;
    render();
  });

  // Live while the app runs, whether or not the section is on screen, so arriving shows nothing stale.
  // The thousand-row cap is the read's: anything older is in the file.
  options.bridge.onLogAppended((entry) => {
    entries.push(entry);
    if (entries.length > LOG_READ_COUNT) entries = entries.slice(-LOG_READ_COUNT);
    render();
  });

  return {
    element,
    async open() {
      input.focus();
      try {
        const read = await options.bridge.readLog();
        entries = read.entries;
        file.textContent = read.file;
        options.onError('');
      } catch (error: unknown) {
        options.onError(`Log not read: ${failureText(error)}`);
      }
      render();
    },
    focus: () => input.focus(),
    runAction(action) {
      if (action.kind === 'log-select') {
        selected = clampIndex(selected + (action.direction === 'up' ? -1 : 1), shown.length - 1);
        render();
      }
      if (action.kind === 'log-open') toggle();
      if (action.kind === 'log-filter-reset') {
        input.value = '';
        selected = 0;
        render();
      }
    },
  };
}
```
